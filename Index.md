
# Development Environment

This directory documents my development environment.

The goal is to preserve everything that makes this environment productive so I can rebuild it or quickly get back up to speed after a long break.

## Philosophy

Things I try to optimize for:

- Owning my own data.
- Reducing repetitive work.
- Using the keyboard whenever it makes sense.
- Keeping the system understandable.
- Choosing simple solutions over clever ones.
- Documenting anything I'll probably forget.
